# 图标 · 几何比例变体 (斐波那契规格)

第四个文件夹。与 `../icons`(线上)、`../icons-stylized`(软几何)、`../icons-sharp`(锐几何) 并存。
这一套不是"手摆坐标", 而是**先从数学规格出发, 再让几何长出来**, 并且构建时自动校验。

## 规格 (96 网格, 中心 48)

| 项 | 值 |
| --- | --- |
| 度量序列 | **Fibonacci**: 3 · 5 · 8 · 13 · 21 · 34 · 55 |
| 光学 keyline | 圆 d=68 · 方 60 · 竖矩 52×68 · 横矩 68×52 |
| 线宽 / 缝隙 | 主 8 · 中 5 · 细 3（全书脊缝 5, 环带线宽 10） |
| 圆角 | 大 13 · 中 8 · 小 5（全部取自序列） |
| 角度 | 只用 45° / 60° / 120° |
| 光学补偿 | 圆与尖端外扩 1.5 单位（避免视觉缩水） |

### 关键: 按 keyline 自动配形
手写坐标永远配不准（例如等边三角形的 60° 顶点，圆角退距 = r/tan30° = 1.73r，
r=8 就会吃掉 13.9 单位，肉眼看上去"莫名其妙变小了"）。所以 `build_golden.py` 的做法是：

1. 按规格写出几何 → 2. 渲染并测量真实 bbox → 3. 等比缩放到该图标的 keyline 目标 →
4. 平移到画布中心 → 5. 用最终几何出图。

每个图标的目标 bbox：play 58×58（三角形面积随边长平方涨, 需比方形小才不会显重）·
next 68×68（圆 keyline）· read 66×48（横矩）· like 58×58 · block 60×60。

- **墨量**(96 网格内实心面积)全部落在 1670~2356, 均值 2084。环形天然比实心盘轻、三角天然比方形轻,
  这是图标设计的固有现象, 因此**用 keyline 而不是等面积**来配平; 墨量表只作体检指标。
- **bbox 全部落在 keyline 内** ✓（构建时自动断言）

## 逐图标构造

- **播放**：等边三角形（内角 60°）, 边长 66 → 高 66×√3/2 = 57.2, 圆角 8, 尖端外扩 1.5
- **换一条**：两段 **120° 圆弧**（半径 29, 线宽 10） + **两处 60° 缺口** + 60° 楔形箭头（16×25）, 外缘正好落在圆 keyline d68
- **阅读**：书脊 8 宽（圆角 5, 高 48） + 两页 24×44（圆角 5, 与书脊各留 5 缝）, 总宽 24+5+8+5+24 = 66
- **喜欢/不喜欢**：掌 45→79（高 34）· 拇指高 31、根宽 22、60° 虎口（r=5）· 袖口 13×34, 与掌留缝; 不喜欢 = 同形 `rotate(180 48 48)`
- **屏蔽**：正圆 d=60（用方 keyline 配平墨量） + 45° 斜杠（宽 8, 圆帽贯通）

共同点：**纯白 `#ffffff`、零渐变**；缝隙与斜杠都是真透明；全部只用直边 + 圆弧 + 45°/60° 角。

## 目录内容 / 命令

```
icons-golden/
├─ play.svg next.svg read.svg like.svg dislike.svg block.svg
├─ icons.svg                     sprite(currentColor)
├─ png/<name>-{24,48,96,192}.png
├─ preview.png / preview.html    预览拼版(含 keyline 构造网格面板)
├─ build_golden.py               规格 + 几何 + 自动配形 + 墨量/keyline 报告
└─ check_svg.py                  自检: SVG 与 PNG 几何一致性
```

```bat
cd desktop\web\icons-golden
python build_golden.py     :: 重建 + 打印墨量/keyline 体检表
python check_svg.py        :: SVG 与 PNG 是否同一几何
```

## 想换成这一套

1. `app.js` 6 处 `icons/xxx.svg` → `icons-golden/xxx.svg`；
2. `app.py` 的 `_ICON_PATH_RE` 增加 `icons-golden` 前缀；
3. `android/build_apk.py` 的 `WEB_DIRS` 加 `"icons-golden"`；`sync_app_src.bat` 加一行 xcopy；
4. `style.css` 白天主题反相规则不用改。
