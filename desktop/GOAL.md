# GOAL · 洞鉴虚明桌面版 v0.2.9 —— 内置浏览器·标签页（不再跳外部浏览器）

> 分支：`desktop-embedded-browser` · 起始版本 v0.2.8.5a · 目标版本 **v0.2.9.0a**
> 本文是本分支的总目标与任务分解，做一项勾一项；全部勾完即达成目标。
> **v2 改版（用户反馈）**：跳转不弹新窗口，而是主窗口内新增**内置浏览器标签页**。

---

## 0. 一句话目标

**让桌面端成为真正的"桌面软件"：双击后弹出自带的应用窗口；点 feed 卡片/消息/账号里的任何
视频或帖子，都在主窗口内新增一个内置浏览器标签页打开（右上标签条可切换/关闭），
全程只有一个窗口、不拉起系统默认浏览器。**

## 1. 背景与问题

现状（v0.2.8.x）：桌面端 = 纯标准库本地服务（`app.py`，HTTP 127.0.0.1:8000）+
外部默认浏览器打开页面。所有跳转（B站视频、贴吧帖子、小黑盒、消息中心、B站主页）都通过
`window.open(url, "_blank")` 落到**系统浏览器**：

- 主界面不在应用窗口里，像"开了个网页"而不是"打开了一个软件"；
- 点一个视频就切走/新开浏览器标签，与主界面割裂，多屏来回切很烦；
- 无法控制跳转窗口的外观与生命周期（关软件后浏览器标签还挂着）。

## 2. 技术选型（开源调研，已实测验证 ✅）

要求：内嵌完整现代浏览器内核（要能放 B 站视频）、能被 PyInstaller 打成单文件 exe、
Python 3.14 兼容。调研结论：

| 方案 | 结论 |
|---|---|
| **pywebview**（GitHub `r0x0r/pywebview`，MIT） | **✅ 采用**。Windows 走系统自带的 **WebView2（Edge Chromium）** 运行时；自带 PyInstaller hook（自动收集 WebView2 全套 DLL）；JS⇄Python 双向桥、运行时多窗口、evaluate_js 注入均可用 |
| PySide6 + QtWebEngine | 备选。自带 Chromium 但体积 +150MB+，放弃 |
| cefpython | 停止维护，无 py3.14 支持，放弃 |
| `msedge --app=URL` 模式 | 仍是外部浏览器进程，不符合"内置"，放弃 |

**本机尖刺实测（2026-10-02，Win10 19045 + Python 3.14.7 + pywebview 6.2.1/pythonnet 3.2.0）**：

1. WebView2 窗口打开成功，内核 `Chrome/154 + Edg/154`；
2. js_api 桥：本地页面与**远程页面（bilibili.com）**都能回调 Python（`BAR_BTN_OK: remote-test`）；
3. `evaluate_js` 可向远程页注入悬浮工具条（幂等注入成功）；
4. 运行中可随时 `create_window` 弹出第二个内置浏览器窗口（子窗口标题/URL 正确）；
5. WebView2 对 B 站 H5 播放器/登录页渲染正常；
6. 已知限制：页面内 JS `window.close()` 被内核禁止 → 关窗按钮必须走桥回调 Python `destroy()`（已验证可行）。

## 3. 目标体验（用户视角）

1. 双击 `启动.bat` 或 `dist\洞鉴虚明v0.2.9.0a.exe` → **弹出应用主窗口**（非浏览器）。
2. 点 feed 卡片 / "打开原帖" / 消息中心 / B站账号页 / 大图模式跳转 → 主窗口内
   **新增一个内置浏览器标签页**：窗口顶部是**原生"浏览器式"标签栏**（信息流为固定
   首页标签，无关闭按钮；新标签显示页面标题、悬停可见 ✕ 关闭），点击标签切换。
   标签栏属于窗口部件，不遮挡任何网站内容。
3. 标签页里可以继续点站内链接（同一标签内跳转，标签标题跟随页面标题）；
   站内 target=_blank 弹新页 → 也变成一个新标签页。
4. **切换标签零重载**：每个标签页是独立的 WebView2 实例（共享浏览器进程与登录
   数据），切换只改可见性——首页信息流永不重载、视频切走再切回继续播。
5. **无边框窗口**：原生标题栏移除，标签栏兼任标题栏——空白处拖动窗口、右端
   ─ □ ✕ 窗口按钮（悬停高亮、关闭悬停变红）；**边缘缩放**：左右/下边贴 4dp 热区、
   标签栏上缘 4dp 为顶边缩放带（客户区被 WebView2 全覆盖, THICKFRAME 的缩放带
   收不到鼠标 → 必须自建热区, 按下进入系统缩放循环），最大化时不响应。
6. **标签外观**（浏览器式）：顶圆角矩形贴住栏底、激活标签=面板色+顶部强调条
   （主题粉）、非激活悬停微亮，不再是素胶囊。
7. **内置浏览器深浅跟随主界面**：黑夜模式下站点页面自动转深色（Chromium
   PreferredColorScheme + 页面内自愈反色兜底），白天模式恢复——点 B 站视频不再
   白屏刺眼；主题切换实时生效。
8. **标签栏强调色跟随设置文件的强调色**（绿色强调色 → 标签强调条变绿），
   且壳内页面首启会从服务端设置恢复主题/强调色（webui 与壳设置互通）。
8. 切回信息流标签时设置栏不再出现白色焦点框（页面焦点环已去掉）。
9. **任何时刻只有一个应用窗口**；关闭主窗口 → 应用进程退出、悬浮球收走、服务关闭。
10. **零降级死角**：未装 WebView2 运行时/库缺失的机器 → 自动回退到"外部浏览器模式"
   （现行为），弹一次提示，绝不白屏。
8. 兼容性不变：CLI `python app.py` 纯服务模式保留；二次双击检测到服务已运行时只开窗口。

## 4. 架构设计（v2：单窗口标签页）

```
┌─ app_window.py(新,窗口壳,exe 入口) ────────────────────────────┐
│ 1. import app → app.run_server(auto_open=False) 起服务(线程)    │
│ 2. 检测 WebView2 运行时(注册表) → 缺失则回退外部浏览器模式       │
│ 3. 唯一的 pywebview 主窗口(无边框) + ShellApi(js_api)            │
│ 4. shell_pages.py 控件池: 每标签页一个 WebView2 控件             │
│    (共享用户数据目录) → 切换=可见性切换, 页面零重载              │
│ 5. 窗口顶部原生标签栏(shell_tabstrip.py): 兼任标题栏             │
│    (拖拽/双击最大化/─ □ ✕ 窗口按钮)                              │
│ 6. 关闭主窗口 → app.shutdown() 收尾(悬浮球/线程池/DB/服务)       │
└────────────────────────────────────────────────────────────────┘
        │ window.pywebview.api.*                     ▲ evaluate_js 注入
        ▼                                            │
┌─ web/app.js ──────────────┐   ┌─ 内置浏览器标签页(同一窗口内) ─────┐
│ openExternal(url):        │   │ open_in_app: 去重→新标签→导航     │
│  有壳 → api.open_in_app   │ → │ 站内链接: 当前标签内跳转          │
│  无壳 → window.open(降级)  │   │ 标签条: 切换/关闭/刷新/系统浏览器  │
└───────────────────────────┘   └──────────────────────────────────┘
```

实现说明（v4）：**活标签已落地**——每个标签页是独立的 WebView2 控件（pythonnet
直接实例化 `Microsoft.Web.WebView2.WinForms.WebView2`，创建属性克隆自主控件，
共享用户数据目录），切换 = 可见性切换，首页信息流永不重载、视频跨标签续播；
站内弹新页(NewWindowRequested)转成新标签页，标题经 DocumentTitleChanged 同步。
控件必须经 form.BeginInvoke 在 UI 线程创建/操作（跨线程建父子直接抛异常）。
标签栏用 WinForms 自绘 Panel（Paint 事件 + MouseClick 命中测试；pythonnet 的
OnPaint 虚方法重写不可靠，必须走事件订阅——踩坑记录）。无边框缩放：
FormBorderStyle=None 后补回 WS_THICKFRAME 样式位恢复原生边缘缩放与 Aero Snap，
最大化前设 MaximizedBounds=工作区避免盖住任务栏。

模块职责：

- **`app.py`（改动最小化）**：把 `__main__` 里的服务启动序列抽成 `run_server(auto_open=False) -> (server, port)`
  与 `shutdown(server)`（收尾：serve 关闭、悬浮球、线程池、tb 登录）；CLI 行为逐字不变。
  悬浮球内证据链接维持 `webbrowser.open`（tkinter 独立进程无法共享 WebView2，属辅助场景）。
- **`app_window.py`（新）**：窗口壳与 exe 入口。职责：起/复用服务、WebView2 检测、
  唯一主窗口、ShellApi（标签页管理：`open_in_app`/`tab_switch`/`tab_close`/
  `open_external`/`shell_info`）、退出收尾、降级路径。
- **`shell_tabstrip.py`（新）**：窗口顶部原生"浏览器式"标签栏（WinForms 自绘）：
  信息流固定标签 + 各页签（标题/✕ 关闭/点击切换）；无边框窗口下兼任标题栏
  （空白拖动/双击最大化/─ □ ✕ 窗口按钮）。
- **`shell_pages.py`（新）**：WebView2 控件池——每标签页一个控件（共享用户数据
  目录），切换=可见性切换零重载；无边框缩放补丁也在此打。
- **`web/app.js`**：新增 `openExternal(url)` 统一出口（探测 `window.pywebview.api`，
  有壳走桥，无壳原样 `window.open`）；替换全部 10 处 `window.open` 调用点。
- **`启动.bat` / `构建exe.bat` / spec**：入口换成 `app_window.py`；新增 `启动-服务模式.bat`。

安全约束：ShellApi 只接受 `http(s)://` URL（页面侧只能让它开网页，无法触发本地文件/命令）；
`OPEN_EXTERNAL_LINKS_IN_BROWSER=False` 保证站点弹新页请求也在当前标签内导航。

## 6. 风险与降级

| 风险 | 缓解 |
|---|---|
| 目标机器无 WebView2 运行时 | 启动时注册表检测 → 提示 + 自动回退外部浏览器模式（现行为，不白屏） |
| pythonnet/PyInstaller 打包踩坑 | hook 已自带；已实测打包成功，失败则 hiddenimports/`--collect-all webview` 兜底 |
| B站等站点内核策略变化（DRM/UA） | WebView2 即 Edge 内核，与用户日常浏览器同源；必要时补 UA/`--disable` 开关 |
| 前端在非壳环境（安卓壳/普通浏览器）误走桥 | 桥探测仅 `window.pywebview` 存在时生效，安卓壳路径不受影响 |
| 二次启动端口占用 | 沿用 `port_busy` 探测：只开窗口指向已运行服务，不重复起服务 |
| 标签栏遮挡站点内容 | 已消除：标签栏是窗口原生部件，站点页面在其下方渲染，零遮挡 |
| 多控件内存占用 | 各控件共享同一浏览器进程（仅渲染器独立）；站点页数量用户可控（可关） |
| 无边框无法缩放/盖任务栏 | WS_THICKFRAME + 自建贴边缩放热区(THICKFRAME 缩放带在 WebView2 覆盖下收不到鼠标)；MaximizedBounds=工作区 |
| 拖边缘缩放变成拖走窗口 | 原因同上(鼠标落入标签栏空白触发了移动)；已由热区+上缘缩放带修复 |
| 站点页面深浅与主界面不一致(白屏刺眼) | **B站走原生深色**：CookieManager 直接写官方深色开关 cookie(theme_style=dark, 顶栏切换写的就是它)+重载生效；其他站 PreferredColorScheme + 页面内自愈反色兜底(每1.5s重测) |
| 脚本改名后引用不同步(踩坑: _DARK_JS→_SMART_JS 改名漏改引用, NameError 被吞, 注入静默失效多轮) | 改名必须全局 grep 旧名；产品异常不要裸 except:pass 吞掉(至少落日志) |
| 壳内页面读不到用户主题/强调色 | 壳内 WebView2 的 localStorage 与外部浏览器独立 → 主题/强调色落服务端设置(ui_theme/ui_accent_id), 页面首启无本地值时从 /api/ui_theme 恢复 |
| 无边框窗体缝隙露白线 | 窗体 BackColor 改深色 + 关闭 DWM 非客户区渲染 |
| 批量替换静默失败(踩坑三次: 绘制块/常量残留/st 顺序) | 替换后必须 grep 验证目标代码真实存在, 再跑 py_compile+运行验证 |
